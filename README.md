# Google Play Books™ Extended Plugin

A Chrome/Firefox extension to add more QoL and UI based features to Google Play Books™, such as Book/Sepia View, Proper Margin support, Invert colors, bubble zoom etc.

It works with all Book types such as flowable EPUB, fixed EPUB, Hybrid EPUB and comics. Features may vary by book type.

- **Note:** Chrome & Firefox Extensions Links at bottom of page.

## Features (in early alpha development, features are not complete yet)

- **Book View** - Get a proper Book Layout with binder, outline shadows and Sepia Background
- **Book Margins** - Add margins on the book to make it look like a real book
- **3D Book Animations** - Turning a page actually turns the pages like a real book
- **Remove Background** from images - Detects and removes backgrounds from images in books
- **Bubble Magnify** - Zoom into comic book bubbles to read them easily
